# CYBERQUEST VR — sitio público

Sitio estático informativo, política de privacidad y soporte. Publicado con GitHub Pages, sin dependencias, scripts, formularios ni analítica añadida.

- `index.html`: información del juego.
- `privacidad.html`: política de privacidad, versión 1 del 17-11-2026.
- `soporte.html`: contacto y solicitudes.
- `styles.css`: presentación adaptable y estilos de impresión del navegador por defecto.

No contiene código Unity, APK, evidencias de participantes ni credenciales. El repositorio del juego es independiente y conserva su visibilidad privada.

La política corresponde al candidato 1.0.57-nexo. Revisar antes de incorporar nuevos servicios remotos o cambiar el almacenamiento. El documento informa del funcionamiento revisado; no constituye certificación jurídica ni aprobación de Meta. No atribuye patrocinio, titularidad o representación institucional a UDLA.
